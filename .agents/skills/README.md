# Project Skills

Project-specific skills live in this folder (`.agents/skills/`) — the cross-IDE Agent Skills convention. Committed to git, so they are shared across machines and readable by every agent IDE.

Any agent can invoke any skill. Skills are agent-agnostic - they are procedures, not roles.

> **This file is generated.** Regenerate after adding, removing, or renaming a skill:
> `python3 .ai/core/install/skills-index.py --dir .agents/skills`
